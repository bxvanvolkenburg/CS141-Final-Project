# CS141-Final-Project

## Project Description

This is CS141 Java Final Project, completed by Burgundy Van Volkenburg & Katie Smith.

We have been running the code in an online compiler by selecting all of the code and pasting it.

This menu shows options for women in STEM, scholarship calculation, upcoming educational & support resources for women and a recommendation to join SWE here at EVCC.

## Features

- **Navigation for jobs for women in STEM** - Top 3 job recommendations including Software Engineer/Developer, Data Scientist/Data Analyst, and Cybersecurity Specialist
- **Scholarships for women in STEM** - E-Stem Scholarship eligibility calculator based on credit hours
- **Educational resources for women in STEM** - Upcoming conferences in chronological order
- **STEM clubs (SWE)** - Contact information for the EvCC STEM Club
- **Support for women in STEM** - Links to Girls Who Code and AAUW resources

## How to Use

Run the Menu.java file in an online Java compiler by selecting all of the code and pasting it into the compiler. Follow the on-screen prompts to navigate through the different menu options.
